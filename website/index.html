Stop leaking secrets
on screen share

ShareStopper watches your screen during Zoom, Meet, Teams, Discord, and Slack calls. When it spots an API key, password, credit card, or any sensitive data — it hides it before anyone else can see it.

Terminal
# Install ShareStopper
npm install -g sharestopper
What it does

Real-time privacy protection that runs locally

Activates automatically Detects when Zoom, Google Meet, Teams, Discord, or Slack begins sharing your screen. No manual toggle — it just works.
29 data types detected API keys, passwords, credit cards, JWTs, SSH keys, database URIs, emails, IPs, webhooks, environment variables, and more.
Sub-millisecond detection Pattern matching takes 0.11ms. Full pipeline — capture, OCR, detect, overlay — runs under 600ms. Hidden before anyone can read it.
Runs on localhost Everything stays on your machine. No cloud, no telemetry, no data leaves your network. The dashboard runs at localhost:1011.
Live dashboard See every detection in real time — what was caught, which app it came from, confidence level, and timing. Edit rules from the browser.
Open source MIT licensed. Every regex pattern, every detection rule — fully inspectable and customizable. Add your own patterns or adjust sensitivity.
Pipeline

How it works

01
Screen sharing detectedMonitors Zoom, Google Meet, Teams, Discord, and Slack for active screen sharing using macOS system APIs and process inspection.
02
Screen capturedCaptures the current display at native resolution. Frame differencing means only changed regions get re-scanned.
03
Text extracted via OCRTesseract.js extracts all visible text with word-level bounding boxes for precise overlay positioning.
04
Pattern matching in 0.1ms26 compiled regex patterns run against extracted text — API keys, passwords, credit cards, IPs, emails, JWTs, SSH keys, database URIs, webhooks.
05
Overlay renderedBlock, blur, or pixelate overlays appear over matched regions. Invisible to your workflow, opaque to viewers on the call.
