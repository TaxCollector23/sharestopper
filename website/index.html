How it works

Five stages, under 600ms

1
Screen sharing detected

Monitors Zoom, Google Meet, Teams, Discord, and Slack for active sharing using macOS system APIs and process inspection. Activates automatically — no manual toggle.

~0ms
2
Screen captured

Native-resolution capture via macOS screencapture. Frame differencing means only changed regions get re-scanned on subsequent passes.

~200ms
3
Text extracted

Tesseract.js OCR extracts all visible text with word-level bounding boxes, giving precise coordinates for overlay placement.

~400ms
4
Patterns matched

38 compiled regex patterns with trie-based prefix matching scan the text for API keys, passwords, credit cards, IPs, emails, JWTs, SSH keys, database URIs, webhooks, env vars, SendGrid, npm, Vault, Vercel, and more. See benchmarks.

0.11ms
5
Overlay rendered

Block, blur, or pixelate overlays appear over matched regions. Invisible to your workflow, opaque to everyone on the call.

<1ms
Coverage

38 sensitive data types

Every pattern tested against real-world formats. 158 tests passing. Zero false positives on normal code and conversation.

Credentials

  • API keys (OpenAI, Anthropic, AWS, GitHub, Stripe, Google, SendGrid)
  • Secret keys & access tokens
  • Passwords (env vars, inline, DB connection strings)
  • OAuth client secrets
  • Bearer tokens
  • Session cookies
  • Environment variables

Tokens & Keys

  • JWT tokens (three-segment base64)
  • SSH / RSA private key headers
  • Webhook URLs (Slack, Discord)
  • Twilio credentials
  • Vendor tokens (Vercel, Netlify, Vault, npm, Doppler)

Financial & PII

  • Credit card numbers (Visa, Mastercard, Amex, Discover)
  • Email addresses
  • Phone numbers (US, international)
  • IPv4 addresses (public + private ranges)

Infrastructure

  • Database URIs (MongoDB, Postgres, MySQL)
  • JDBC connection strings
  • Firebase & Supabase configs
