Documentation

Install, configure, and use ShareStopper.

Install

ShareStopper requires macOS and Node.js 18+. Install with one command:

npm install -g sharestopper

This installs to ~/.sharestopper, starts the watcher on localhost:1011, and configures it to auto-start on login via launchd.

Dashboard

Once running, open http://localhost:1011 in your browser. The dashboard shows:

  • Live detection feed — every match as it happens, with type, source app, confidence, and timing
  • Protection status — whether screen sharing is active and which app triggered it
  • Detection rules — toggle individual patterns on/off, adjust sensitivity
  • Profiles — switch between developer, business, student, and streamer presets
  • Analytics — detection counts by type, timeline of activity, false positive rate

How detection works

ShareStopper monitors for screen sharing sessions across Zoom, Google Meet, Teams, Discord, and Slack. When sharing is detected:

  • The current screen is captured using macOS screencapture
  • Tesseract.js extracts text with word-level bounding boxes
  • 26 regex patterns scan for sensitive data (API keys, passwords, credit cards, etc.)
  • Overlays are rendered over matched regions — block, blur, or pixelate

The full pipeline runs in under 600ms. Pattern detection alone takes 0.11ms. See benchmarks for detailed numbers.

Supported data types

29 types across these categories:

  • API keys — OpenAI, Anthropic, Google AI, AWS, GitHub, Stripe, Twilio, Firebase, Supabase
  • Credentials — passwords, OAuth client secrets, bearer tokens, session cookies, environment variables
  • Tokens — JWTs, SSH/RSA private keys
  • Financial — credit card numbers (Visa, Mastercard, Amex)
  • PII — email addresses, phone numbers, IPv4/private IP addresses
  • Infrastructure — MongoDB URIs, Postgres connection strings, Slack webhooks, Discord webhooks

Screen sharing detection

Each app is detected differently:

  • Zoom — checks for CptHost and ZoomShareToolbar processes, plus window title matching
  • Google Meet — monitors Chrome window titles and macOS screen recording indicator
  • Teams — window title inspection for sharing state
  • Discord — Go Live process and window detection
  • Slack — huddle sharing state via window monitoring

Configuration

Edit settings from the dashboard or modify ~/.sharestopper/config.json directly:

{
  "port": 1011,
  "overlayStyle": "block",
  "profile": "developer",
  "autoStart": true,
  "notifications": true,
  "patterns": {
    "openai-key": true,
    "credit-card": true,
    "password": true
  }
}

CLI usage

# Start the watcher
sharestopper

# Run on a custom port
sharestopper --port 8080

# Run benchmarks
sharestopper benchmark

# Run detection tests
sharestopper test

Uninstall

launchctl unload ~/Library/LaunchAgents/com.sharestopper.app.plist
rm -rf ~/.sharestopper
rm -f /usr/local/bin/sharestopper
